Kein klinisches Verfahren

Dieser Test ist ein Selbsteinschätzungs- und Bildungsinstrument. Er ersetzt keine professionelle psychologische Diagnostik (z. B. WAIS-IV, IST-2000-R, CFT 20-R) und liefert keine medizinisch oder juristisch verwertbaren Ergebnisse. Details im Haftungsausschluss.

Was wird gemessen?

Sechs Broad Abilities aus dem Cattell-Horn-Carroll-Modell (CHC):

Gf · Schlussfolgerndes Denken

Matrizen, Zahlenreihen, Analogien, Klassifikationen. Das Kernstück flexibler Intelligenz.

Gc · Verbale Intelligenz

Wortschatz, Analogien, Allgemeinwissen, Sprichwörter. Erworbene Sprachkompetenz.

Gv · Räumliche Verarbeitung

Mentale Rotation, Papierfalten, eingebettete Figuren, Spiegelungen.

Gs · Verarbeitungsgeschwindigkeit

Zeichen- und Zahlenvergleiche unter Zeitdruck. Tempo kognitiver Basisoperationen.

Gsm · Arbeitsgedächtnis

Zifferfolgen vorwärts/rückwärts, Buchstaben-Zahl-Sortieren, kurzfristiges Behalten.

Gq · Mathematisches Denken

Text-, Bruch- und Prozentaufgaben, Zahlenlogik, einfache Gleichungen.

Wie wird gerechnet?

Jede Antwort wird nach Schwierigkeitsgrad gewichtet und gegen eine theoretische Referenzverteilung normiert (Item-Response-Theorie, Rasch-Ansatz). Der Gesamt-IQ wird auf der Wechsler-Skala (M = 100, SD = 15) ausgegeben, inklusive 95 %-Konfidenzintervall (bei angenommener Reliabilität rxx = 0,85). Eine detaillierte Darstellung finden Sie auf der Seite Methodik.

Datenschutz

Der Test läuft vollständig im Browser. Es werden keine Antworten, keine Ergebnisse und keine Identifikationsmerkmale an einen Server übertragen. Optional können Sie Ihr Ergebnis lokal in Ihrem Gerät speichern; diese Speicherung findet ausschließlich in Ihrem Browser statt. Details in der Datenschutzerklärung.
